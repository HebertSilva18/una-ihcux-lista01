# una-ihcux-lista01

Utilizei os seguintes comandos para criar o arquivo "sucesso.txt" no terminal.

cd: Usado para navegar entre pastas.
mkdir: Usado para criar novos diretórios(pastas).
dir: Usado para listar o conteúdo de um diretório, exibindo arquivos e subpastas.

o comando que achei mais complexo até o momento foi o mkdir, por usar menos que os outros e por ter mais caracteres.
